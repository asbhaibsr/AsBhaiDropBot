## ⚖️ Copyright & Legal — Kya Yeh Legal Hai?

<div align="center">

### Haan — 100% Legal. Yahan Proof Hai 👇

</div>

**Yeh bot kaise kaam karta hai:**

- 🗄️ Bot **koi bhi file khud store nahi karta** — nahi koi cloud storage, nahi koi server
- 📡 Sirf aapke **apne private Telegram channel** se files search karta hai

- 📤 File **directly Telegram ke servers se deliver** hoti hai — koi middleman nahi

**Legal Framework:**

- ✅ Telegram ki Terms of Service ke **andar** operate karta hai
- ✅ **Koi public file hosting nahi** — sirf aapka private channel
- ✅ Files **aapki khud ki hain** — jo aapne apne channel mein upload ki hain
- ✅ Bot sirf ek **search + delivery tool** hai — jaise Google Drive search
- ✅ Koi third-party copyright content directly serve nahi karta

> ⚠️ Jo files aap apne channel mein daalte ho, unki zimmedari sirf aapki hai. Bot neutral delivery tool hai.

## 🔑 String Session Kaise Banayein

**Step 1** — Apne PC par terminal kholo

**Step 2** — Install karo: `pip install pyrogram TgCrypto`

**Step 3** — Yeh Python code run karo (ek file banao `gen.py`):

Pyrogram `Client` banao apne `api_id`, `api_hash` ke saath, phone number se login karo, aur `export_session_string()` copy karo.

**Step 4** — Phone number → OTP → Done! Session string copy karo → `STRING_SESSION` mein paste karo

> ⚠️ **String session = aapka Telegram account access.** Kabhi kisi ke saath share mat karo!

> ✅ **Important:** Jis account ka session hai, woh `FILE_CHANNEL` ka member hona chahiye — warna `CHANNEL_INVALID` error aata hai.
