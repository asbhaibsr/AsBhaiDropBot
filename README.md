## 🔑 String Session Kaise Banayein

<div align="center">
<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&weight=700&size=16&duration=2000&pause=800&color=58A6FF&center=true&vCenter=true&width=600&height=40&lines=String+Session+=+Aapka+Userbot+Account+🔑" alt=""/>
</div>

<br/>

> ⚠️ **String Session aapka Telegram account access deta hai — Kabhi kisi ke saath share mat karo!**

### Steps:

**Step 1** — PC par terminal/CMD kholo

**Step 2** — Install karo:
```bash
pip install pyrogram TgCrypto
```

**Step 3** — Ek file banao `gen.py` aur yeh code daalo:
```python
from pyrogram import Client

api_id   = 123456          # my.telegram.org se
api_hash = "your_api_hash" # my.telegram.org se

with Client("my_account", api_id, api_hash) as app:
    print(app.export_session_string())
```

**Step 4** — Run karo:
```bash
python gen.py
```

**Step 5** — Phone number → OTP enter karo → Session string copy karo → `STRING_SESSION` mein paste karo

> ✅ **Dhyan raho:** Jis account ka session banaya hai, woh `FILE_CHANNEL` ka **member** hona chahiye — warna `CHANNEL_INVALID` error aayega!

## 🌐 Blogger + Google Sheet Verify System

<div align="center">
<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&weight=700&size=16&duration=2000&pause=800&color=39D353&center=true&vCenter=true&width=700&height=40&lines=Blog+visit+karo+→+File+pao!+Aur+tum+paise+kamao+💰" alt=""/>
</div>

<br/>

> 💡 **Yeh system kyun use karein?**  
> User ko file milne se pehle aapka blog post visit karna padta hai. Jitne zyada users, utne zyada **blog views = AdSense income**. Sheet mein naya URL add karo — bot automatically pick kar lega!

---

### 📋 Part 1 — Blogger Setup (Owner Se Lena Hoga)

> 🔑 **Yeh step ke liye [@asbhaibsr](https://t.me/asbhaibsr) se contact karo — woh ek special script denge**

Script jo kaam karti hai:
- User blog post par aata hai
- **"Get File 📥"** button dikhta hai  
- User click karta hai → Bot automatically file bhej deta hai
- Aapko kuch nahi karna — sab automatic!

**Script install kaise karein (Owner dega):**

```
Step 1 → @asbhaibsr ko message karo: "Blogger script chahiye"
Step 2 → Woh aapko ek HTML/JS code denge
Step 3 → Blogger Dashboard → Theme → Edit HTML
Step 4 → Code paste karo → Save karo
Step 5 → Apni koi bhi post publish karo
Step 6 → URL copy karo → Google Sheet mein daalo
```

---

### 📊 Part 2 — Google Sheet Setup

**Step 1 — Sheet banao:**

1. [sheets.google.com](https://sheets.google.com) → **New Spreadsheet**
2. **Column A** mein apne blogger post URLs daalo (ek per row):

```
Column A                                                        | Column B (Optional)
https://yourblog.blogspot.com/2025/01/movie-post-1.html        | Action Movies
https://yourblog.blogspot.com/2025/01/series-post-2.html       | Web Series
https://yourblog.blogspot.com/2025/01/comedy-post-3.html       | Comedy
```

**Step 2 — Sheet ko "Publish to Web" karo (ZARURI):**

```
Google Sheets mein:
File (3-dot menu) → Share & Export → Publish to Web
      ↓
Sheet1 select karo
      ↓
Format: "Comma-separated values (.csv)" select karo
      ↓
"Publish" button dabao → OK
      ↓
Link copy karo (ya neeche wala URL use karo)
```

**Step 3 — CSV URL banao:**

Apni sheet ki URL mein se Sheet ID copy karo:
```
https://docs.google.com/spreadsheets/d/  >>>SHEET_ID<<<  /edit
```

Phir yeh URL banao:
```
https://docs.google.com/spreadsheets/d/SHEET_ID/pub?gid=0&single=true&output=csv
```

**Step 4 — Koyeb mein env var set karo:**

```
GOOGLE_SHEET_CSV_URL = https://docs.google.com/spreadsheets/d/YOUR_ID/pub?gid=0&single=true&output=csv
BLOGGER_VERIFY_ENABLED = true
```

**Step 5 — Deploy karo!** Bot automatically:
- 🚀 Start hote hi sheet se saare URLs fetch kar lega
- 🔄 Har **6 ghante** mein auto-sync karega
- ➕ Tum sheet mein naya URL add karo → `/syncsheet` dabao → turant active!

---

### 📝 Part 3 — Blogger Post URL Rules

Har URL yeh hona chahiye:
- ✅ `https://` se start ho
- ✅ Published post ho (draft nahi)
- ✅ Script us post mein install ho (Part 1 dekho)
- ❌ Private/restricted post nahi

Sheet mein naya URL add karna = Ek row add karo → `/syncsheet` = Done! ✅
